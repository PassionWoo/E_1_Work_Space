# 보완 작업 · 재검증 로그

> 2026-10-24 사용자 터미널에서 직접 실행한 명령과 확인된 출력. 일부 `docker ps`의 반복 표시와 장문의 빌드 메타데이터는 핵심 출력만 발췌하였다. 비밀번호 및 개인 Git 사용자 정보는 공개하지 않는다.

## 1. Git 설정과 원격 연결

**입력 대상:** WSL Ubuntu bash, `~/codyssey-precourse`

```text
$ git status -sb
## main...origin/main
$ git config --list | grep -E '^(init.defaultbranch|user.name|user.email|remote.origin.url)=' | sed -E 's/^user\.(name|email)=.*/user.\1=[REDACTED]/' | tee evidence/git-config-sanitized.txt
init.defaultbranch=main
user.name=[REDACTED]
user.email=[REDACTED]
remote.origin.url=https://github.com/PassionWoo/codyssey-precourse.git
```

Git의 최초 Commit 내용과 변경 전의 실제 파일 내용이 같음을 확인:

```text
$ git show HEAD:02_webserver/site/index.html
<h1>Bind Mount Updated Successfully!</h1>
$ cat 02_webserver/site/index.html
<h1>Bind Mount Updated Successfully!</h1>
```

## 2. 원본 HTML과 변경본 분리

```text
$ mkdir -p evidence
$ cp 02_webserver/site/index.html evidence/bind-mount-after.html
$ echo '<h1>Hello from Codyssey Docker!</h1>' > 02_webserver/site/index.html
$ cat 02_webserver/site/index.html
<h1>Hello from Codyssey Docker!</h1>
$ cat evidence/bind-mount-after.html
<h1>Bind Mount Updated Successfully!</h1>
$ git status --short
 M 02_webserver/site/index.html
?? evidence/
```

## 3. 바인드 마운트 변경 전 → 변경 후 → 복구

### 3.1 원본 상태

```text
$ curl -fsS http://localhost:8080
<h1>Hello from Codyssey Docker!</h1>
$ curl -fsS http://localhost:8082
<h1>Hello from Codyssey Docker!</h1>
```

### 3.2 변경본 다시 적용

```text
$ cp evidence/bind-mount-after.html 02_webserver/site/index.html
$ curl -fsS http://localhost:8080
<h1>Hello from Codyssey Docker!</h1>
$ curl -fsS http://localhost:8082
<h1>Bind Mount Updated Successfully!</h1>
```

### 3.3 원상복구

```text
$ echo '<h1>Hello from Codyssey Docker!</h1>' > 02_webserver/site/index.html
$ curl -fsS http://localhost:8082
<h1>Hello from Codyssey Docker!</h1>
$ git status --short
 M 02_webserver/site/index.html
?? evidence/
```

## 4. Docker 이미지 재빌드 및 8083 포트 검증

**입력 대상:** WSL Ubuntu bash

```text
$ docker build -t codyssey-web:verify ./02_webserver
[+] Building 2.2s (7/7) FINISHED
 => CACHED [2/2] COPY site/ /usr/share/nginx/html/
 => naming to docker.io/library/codyssey-web:verify
$ docker run -d --name codyssey-web-verify -p 8083:80 codyssey-web:verify
8ca939f2065b46ab8fba821870f3920b5fdc0203d39a46b5ebc75ef171178a4b
$ curl -fsS http://localhost:8083
<h1>Hello from Codyssey Docker!</h1>
$ docker rm -f codyssey-web-verify
codyssey-web-verify
```

삭제 후 `docker ps -a` 결과에 `codyssey-web-verify`는 더 이상 없었고, 기존 웹 서버 컨테이너 `codyssey-web-8080`, `codyssey-web-8081`, `codyssey-web-bind` 및 데이터 볼륨 컨테이너 `codyssey-volume-b`는 계속 실행 중이었다.

## 5. 보완 결과 요약

- 원본 HTML과 변경본 HTML을 별도 파일로 관리하여 초기 빌드 상태를 재현할 수 있게 함
- 동일한 실행 중 컨테이너에서 바인드 마운트 변경·복구 확인
- 기존 이미지 대신 새 검증용 이미지를 빌드하고 새로운 컨테이너에서 독립 실행 확인
- 별도의 Git 설정 출력 자료를 개인정보 마스킹 후 저장
- 로컬 변경 파일 및 새 증거 자료는 최종 Commit·Push 전 상태이므로 GitHub에 반영되었다고 주장하지 않음
