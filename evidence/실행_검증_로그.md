# 실행·검증 로그 (핵심 발췌)

> 2026-10-24 실제 실습 내용에서 **명령어와 확인된 결과**를 정리했다. 줄임표(`...`)는 반복적이거나 평가에 직접 필요하지 않은 출력을 생략한 자리이며, 결과를 임의로 변경한 것이 아니다. 원본 PowerShell 전체 홈 디렉터리 목록 및 이메일 주소 등 불필요한 개인정보는 여기에 옮기지 않았다.

## 3. Dockerfile, 이미지 빌드, 포트 매핑

**입력 환경:** WSL Ubuntu bash

```text
$ cat 02_webserver/Dockerfile
FROM nginx:alpine
COPY site/ /usr/share/nginx/html/
EXPOSE 80
$ docker build -t codyssey-web:1.0 ./02_webserver
[+] Building 8.5s (7/7) FINISHED
... [2/2] COPY site/ /usr/share/nginx/html/
... naming to docker.io/library/codyssey-web:1.0
$ docker images
codyssey-web:1.0     6ade5b6f782e ...
$ docker run -d --name codyssey-web-8080 -p 8080:80 codyssey-web:1.0
ec50df610ef49c13b932c17c8f314fb267bf3db222cc9f759ccbd5c2de28c2bb
$ docker run -d --name codyssey-web-8081 -p 8081:80 codyssey-web:1.0
c43e4ad1ba4a12e019c68e1aedfa57174cc8bfd7e7d50af1e9697e5727341d9c
$ docker ps
... codyssey-web-8081 ... 0.0.0.0:8081->80/tcp
... codyssey-web-8080 ... 0.0.0.0:8080->80/tcp
```

## 4. 바인드 마운트

```text
$ docker run -d --name codyssey-web-bind -p 8082:80 --mount type=bind,source="$(pwd)/02_webserver/site",target=/usr/share/nginx/html,readonly codyssey-web:1.0
af610f62d48af55c99bbd0321cba5a0cd33249ed231292a322e5bf5ab2560807
$ echo '<h1>Bind Mount Updated Successfully!</h1>' > 02_webserver/site/index.html
$ cat 02_webserver/site/index.html
<h1>Bind Mount Updated Successfully!</h1>
```

검증: 8080·8081은 최초 출력 유지, 8082는 변경된 HTML 표시.
